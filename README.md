# 신기전(神機箭) 3D

조선의 로켓 **신기전**과 그 발사 수레 **문종 화차(신기전기)**를 3D로 살펴보는 교육용 웹앱입니다. 화차를 짜임·맞춤·이음으로 조립해 보고, 신기전의 구조와 화약의 원리를 배우고, 복원 비행실험 값으로 계산한 발사 시뮬레이션을 해 볼 수 있습니다.

## 탭

| 탭 | 내용 |
|---|---|
| 제작(짜임·맞춤·이음) | 바퀴통 → 바퀴살(장부맞춤) → 바퀴테(나비장이음) → 굴대(차축형, 고정)·비녀장 → 차체(옆판으로 높임, 관통장부+쐐기) → 바닥(제혀쪽매) → 신기전기 상자(사개맞춤) → 원공목통 100개(굴대 바로 위) → 뒤로 기울여 각도 잡기(받침 없음, 손잡이를 땅에 대면 약 40°) → 장전. 단계마다 결구 확대 3D와 「기록 / 추정」 표시, 부재 떼어 보기 |
| 신기전 구조 | 대·산화·중·소신기전 실제 크기 비교, 각 신기전 확대, 대신기전 약통 단면(한지 벽·화약·약선구멍·분사구멍·마개·발화통), 치수표 |
| 화약 | 흑색화약 재료와 역할, 염초가 귀했던 까닭, 『신전자초방』 염초 제조 10단계(역사), 약통에 화약 다지기(병기도설) 애니메이션, 안전 안내 |
| 발사 시뮬레이션 | 신기전 종류, 화약 양, 발사각, 철침 길이(280/350mm), 발사대 레일(1.2/3.3m), 발화통 장착(텀블링), 바람. 대·산화 = 발사대 1발, 중·소 = 화차 100발(15발씩 층별). 3D 비행 + 궤적 그래프 + 실험 사거리 띠 |
| 퀴즈 | 8문항 |

**추정·가정값** (앱에 표시)
- 결구(짜임·맞춤·이음) 방법: 기록이 없어 전통 목공 기법으로 복원
- 바퀴살 12개, 바퀴테 6조각, 가로대 수, 옆판 높이 0.65m·굴대 뒤 손잡이 1.5m(손잡이를 땅에 대면 약 40°가 되도록 정한 비례), 신기전기 상자 구조
- 피해 반경(대 5·산화 12·중 1.5·소 0.3m, 바꿔 볼 수 있음), 화차 옆 퍼짐 ±1.5°
- 시뮬레이션: 지상연소 약통 화약 3,000g, 공기 저항(대신기전 2차 실험 3번 사거리에 보정), 중·소신기전 화약 양·무게, 층별 발사 간격 0.6s, 각도 퍼짐 ±2.5°

자료 사이 불일치: 대신기전 약통 겉지름 기록(102mm)이 안지름+두께×2(95.5mm)와 맞지 않음 — 복원 약통은 95.5mm.
