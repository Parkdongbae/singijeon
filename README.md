# 신기전(神機箭) 3D

조선의 로켓 **신기전**과 그 발사 수레 **문종 화차(신기전기)**를 3D로 살펴보는 교육용 웹앱입니다. 화차를 짜임·맞춤·이음으로 조립해 보고, 신기전의 구조와 화약의 원리를 배우고, 복원 비행실험 값으로 계산한 발사 시뮬레이션을 해 볼 수 있습니다.

## v2에서 달라진 것

- **쉬운 화면** — 번호 붙은 메뉴(① 만들기 ② 구조 ③ 화약 ④ 발사 ⑤ 퀴즈), 큰 글자·큰 버튼, 「쉬운 설명」이 먼저 나오고 치수·근거는 「더 알아보기」로 펼쳐 봅니다. 발사는 종류·화약 양·발사각 세 가지만 보이고 나머지는 「고급 조건」에 접혀 있습니다.
- **설정 메뉴(⚙)** — 글자 크기, 화면 색(밝게·어둡게·고대비), 설명 수준, 그래픽 품질(자동·낮음·보통·높음), 3D 이름표, 소리, 움직임 줄이기, 기록 지우기. 기기에 저장됩니다.
- **새 3D** — 대기 산란 하늘과 환경광, 부드러운 그림자, 흙 마당·풀밭·먼 산, 모서리를 둥글린 나무 부재와 나뭇결, 휜 바퀴테·깎은 살·쇠테, 실제로 뚫린 원공목통 구멍, 불꽃·연기·탄착 먼지.
- **내 기록(🏅)과 과녁 맞히기** — 메뉴 완료 표시, 배지 8개, 과녁 미션 3개(별), 퀴즈 별. 회원 가입 없이 기기에만 저장합니다.
- **효과음** — 음원 파일 없이 Web Audio로 합성(끌 수 있음).

## 메뉴

| 메뉴 | 내용 |
|---|---|
| ① 만들기 | 바퀴통 → 바퀴살(장부맞춤) → 바퀴테(나비장이음) → 굴대·비녀장 → 차체(관통장부+쐐기) → 바닥(제혀쪽매) → 신기전기 상자(사개맞춤) → 원공목통 100개 → 뒤로 기울여 각도 잡기(약 40°) → 장전. 단계마다 쉬운 설명, 「더 알아보기」에 짜임 확대 3D와 「기록 / 추정」 표시, 부재 떼어 보기 |
| ② 구조 | 대·산화·중·소신기전 실제 크기 비교, 각 신기전 확대, 대신기전 약통 단면, 치수표 |
| ③ 화약 | 카드 3장: 재료 세 가지 · 염초 만들기(『신전자초방』 10단계) · 약통에 채우기(병기도설) 애니메이션. 안전 안내는 항상 보임 |
| ④ 발사 | 신기전 종류, 화약 양, 발사각 + 「고급 조건」(철침 길이, 발사대 레일, 발화통, 바람, 피해 반경). 대·산화 = 발사대 1발, 중·소 = 화차 100발. 3D 비행 + 궤적 그래프 + 실험 사거리 띠. **과녁 맞히기** 미션 3개 |
| ⑤ 퀴즈 | 8문항, 별 0~3개, 틀린 문제 다시 풀기 |

**추정·가정값** (앱에 표시)
- 결구(짜임·맞춤·이음) 방법: 기록이 없어 전통 목공 기법으로 복원
- 바퀴살 12개, 바퀴테 6조각, 가로대 수, 옆판 높이 0.65m·굴대 뒤 손잡이 1.5m(손잡이를 땅에 대면 약 40°가 되도록 정한 비례), 신기전기 상자 구조
- 피해 반경(대 5·산화 12·중 1.5·소 0.3m, 바꿔 볼 수 있음), 화차 옆 퍼짐 ±1.5°
- 시뮬레이션: 지상연소 약통 화약 3,000g, 공기 저항(대신기전 2차 실험 3번 사거리에 보정), 중·소신기전 화약 양·무게, 층별 발사 간격 0.6s, 각도 퍼짐 ±2.5°

자료 사이 불일치: 대신기전 약통 겉지름 기록(102mm)이 안지름+두께×2(95.5mm)와 맞지 않음 — 복원 약통은 95.5mm.

## 만들기

```
npm install
npm run build   # index.html (오프라인에서도 열림)
npm test        # 치수·실험값 재현 11개 + v2 규칙 4개
```

three.js 0.160, esbuild.
