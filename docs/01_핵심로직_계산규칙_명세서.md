## 2. 비행 계산 `fly(o)`

### 2.1 입력

| 키 | 뜻 | 기본값 | 비고 |
|---|---|---|---|
| `type` | `dae` / `sanhwa` / `jung` / `so` | (필수) | |
| `prop` | 화약 양(kg) | `FLY[type].prop` | 슬라이더 값은 `propMin + (propMax−propMin) × u`, u = 0~1 |
| `angle` | 발사각(°) | 60 | 화면 슬라이더 5~70. 화차(중·소)는 `min(angle, 최대 발사각)` |
| `core` | 철침 길이 280 / 350 | 350 | 대·산화만 적용 |
| `bomb` | 발화통 장착 | 없음 | 대신기전만 적용 |
| `wind` | 바람(m/s) | 0 | 슬라이더 −8~8, 1 간격 |
| `rail` | 발사대 레일 길이(m) | `FLY[type].rail` | 대·산화 선택값 3.3 / 1.2 |
| `seed` | 난수 씨앗 | 1 | 같은 씨앗 = 같은 결과 |
| `jitter` | 각도 퍼짐(°) | 0 | 화차 일제 발사가 2.5를 줌 |
| `yawJitter` | 옆 퍼짐(°) | `jitter`가 있으면 1.5, 없으면 0 | |

종류별 값 `FLY` (kg 단위, `cda` = 항력계수×단면적 m²):

| type | dry | prop (min~max) | cda | rail | bombKg |
|---|---|---|---|---|---|
| dae | 1.875 | 3.0 (1.5~3.5) | 0.0074 | 3.3 | 0.25 |
| sanhwa | 1.875 | 3.0 (1.5~3.5) | 0.0074 | 3.3 | 0 |
| jung | 0.115 | 0.035 (0.015~0.05) | 0.00097 | 0.23 | 0 |
| so | 0.07 | 0.012 (0.005~0.018) | 0.0003 | 0.23 | 0 |

### 2.2 출력

`range`(사거리 m, `max(0, x)`) · `lat`(옆 어긋남 m, `range × tan(yaw)`) · `maxH`(최고 높이 m) · `time`(비행 시간 s) · `vExit`(레일을 떠날 때 속도 m/s) · `thrust`(평균 추력 N) · `I`(총추력 Ns) · `tb`(추진 시간 s) · `mass0`(처음 무게 kg) · `path`(궤적 `[x, z, t]` 배열) · `tumble`(실제 텀블링했나) · `ev`(레일 이탈·연소 끝·텀블링·정점 시각) · `angle`(°).

### 2.3 계산 단계

| 단계 | 식·규칙 (코드 기준) |
|---|---|
| ① 비추력 | `isp = CORES[core].I / (TEST_PROP_KG × G)`. `TEST_PROP_KG = 3.0` [가정]. 중·소는 core 350의 비추력을 씀 |
| ② 총추력·추진시간 | `I = isp × prop × G`. 추진시간 `tb` = 대·산화는 `CORES[core].tb`(280 → 3.94 s, 350 → 3.81 s), 중·소는 **0.9 s** [가정] |
| ③ 평균 추력 | `thrust = I / tb` (추진 중 일정) |
| ④ 질량 | 처음 `m = dry + prop + bombKg`. 추진 중 매 단계 `m −= prop / tb × dt` (화약이 일정하게 줄어듦) |
| ⑤ 적분 | 시간 간격 `dt = 0.005 s`, 최대 `t < 120 s`. 경로는 10단계(0.05 s)마다 저장 |
| ⑥ 레일 구간 | `s < rail`인 동안 직선 운동: `a = max(0, F/m − G·sin(발사각))`, 속도에 `a·dt`를 더하고 발사각 방향으로 이동. 이 구간은 공기 저항 없음. 레일을 벗어나는 순간 `vExit`·`ev.railExit` 기록 |
| ⑦ 비행 구간 | 바람 반영 상대속도 `rx = vx − wind`, `rz = vz`, `vr = hypot(rx, rz)`. 몸체 방향 `th = atan2(rz, rx)`(깃의 복원력으로 공기 흐름을 따름) |
| ⑧ 항력 | `D = 0.5 × RHO × cda × vr²` |
| ⑨ 가속도 | `ax = (F·cos th − D·rx/vr) / m`, `az = (F·sin th − D·rz/vr) / m − G` |
| ⑩ 착지 | `z < 0` 이고 `t > 0.2`이면 마지막 구간을 선형 보간해 `z = 0` 지점을 마지막 점으로 하고 종료 |

### 2.4 텀블링 (대신기전 + 발화통만)

| 규칙 | 값 |
|---|---|
| 발생 확률 | **75%** (`R() < 0.75`, 실험 표5: 4발 중 3발). 대신기전이고 `bomb`일 때만 난수를 뽑음 |
| 시작 | 이륙 1초 뒤(`t > 1`) |
| 효과 | 몸체 방향에 `sin(spin·6) × 1.6` rad 흔들림 추가, 항력 면적 `cda × 6`, 옆 방향 `±15°` 추가(`(R()−.5)×30`) |
| 화면 문구 | 텀블링 때 경고 상자에 「이륙 약 1초 뒤 빙글빙글…」 표시 |

### 2.5 바람

`wind`는 상대속도에만 들어간다. 뒷바람(+)이면 `rx = vx − wind`가 작아져 항력이 줄고, 맞바람(−)이면 커진다. 바람이 옆으로 불지는 않는다(옆 어긋남은 §3 퍼짐만).

## 3. 화차 일제 발사 `volley(o)`

| 규칙 | 값 | 근거 |
|---|---|---|
| 발수 | 100발 = `GIJEON.rows` 합 (10 + 15×6) | [백과] |
| 층 순서 | `rows`를 뒤집어 **위층(15발)부터** `layer 0` → 맨 아래(10발)가 `layer 6` | [백과] |

| 각도 퍼짐 | `jitter` 기본 **2.5°** → 발마다 `발사각 + (R()−.5)×2×2.5` (±2.5° 균등) | [가정] |
| 옆 퍼짐 | `jitter`가 있으면 `yawJitter` 기본 **1.5°** → ±1.5° 균등 | [가정] |
| 씨앗 | 발마다 `1000 + k × 7919 + (o.seed || 0)` (k = 0~99) | 같은 씨앗 → 같은 100발 |
| 반환 | 각 발의 `fly()` 결과 + `layer, delay, col, n` | |

대·산화는 `volley` 없이 `fly()` 1발만 쏜다(발사 때마다 새 씨앗 `Math.random()×1e6`).

## 4. 최대 발사각 (화차)

손잡이(수레채 뒤끝)가 땅에 닿는 각도. `model.js`에서 0.05° 간격으로 0°부터 늘리며 처음으로 손잡이 높이가 0 이하가 되는 각을 찾는다.

```
손잡이 높이(θ) = R + ys·cosθ − back·sinθ
R    = 바퀴 반지름 = 870mm ÷ 2 = 0.435 m   (CART.wheelD)
ys   = 수레채 높이 = 옆판 높이 0.65 + 0.045 = 0.695 m   (CART_GEO.raise)
back = 굴대 뒤 손잡이 길이 = 1.5 m                         (CART_GEO.back)
최대 발사각 = 높이(θ) ≤ 0 이 되는 첫 θ  → 약 40.15°
```

- 화면 표기는 `Math.round` → **40°**. 기록 [화차]의 「최대 40°」와 맞도록 옆판 높이·손잡이 길이(가정)를 정함.
- 실제 계산·상한 판정에는 반올림하지 않은 약 40.15°를 쓴다.
- 손잡이 높이 표시: `max(0, 높이(min(θ, 최대각))) × 100` cm. 발사각이 최대각을 넘으면 최대각으로 쏘고 안내 문구를 보인다.

## 5. 피해 면적 `impactStats(pts, r)`

`pts` = 탄착점 `[x, y]`(m), `r` = 피해 반경(m, **가정**).

| 항목 | 계산 |
|---|---|
| 범위 | `x0 = min(x) − r`, `x1 = max(x) + r`, `y0·y1`도 같음 |
| 격자 | `N = 160` → 160×160칸, 칸 크기 `dx = (x1−x0)/N`, `dy = (y1−y0)/N` (0이면 1) |
| 판정 | 칸 중심이 어느 한 탄착점 원(반경 r) 안이면 1칸 적중. `r = 0`이면 계산 안 함(면적 0) |
| 면적 | `area = 적중 칸 수 × dx × dy` (원들의 **합집합** — 겹침은 한 번만) |
| 길이·폭 | `len = max(x) − min(x)`, `wid = max(y) − min(y)` (반경 제외, 점들 기준) |
| 중심 | `cx`, `cy` = 점 좌표 평균 |

피해 반경 기본값 `DAMAGE` / 상한 `DAMAGE_MAX` (m, 모두 [가정]): 대 5 / 20 · 산화 12 / 30 · 중 1.5 / 6 · 소 0.3 / 2.

탄착점 좌표: 화차는 `[발사 x0 + range, z0 + lat]`, 대·산화는 `[cos(발사각)×1.5 + range, z0 + lat]`.

| 딱지 | 정의 | 판정 질문 | 표시 |

## 8. 미션 판정 규칙 (확정)

미션은 `{ type, target(m), tol(m) }`. 판정에 쓰는 사거리 `R`:

| 종류 | 판정 사거리 R |
|---|---|
| 화차(중·소) | **100발 평균 사거리** (`volley` 100발의 `range` 평균) |
| 대·산화 | **1발 사거리** (`fly().range`) |

**성공**: `|R − target| ≤ tol`

| 별 | 조건 |
|---|---|
| ★ 1개 | 성공 |
| ★ 2개 | 성공 + `|R − target| ≤ tol / 2` |
| ★ 3개 | 성공 + **3번째 시도 이내**에 처음 성공(시도 = 그 미션을 고른 뒤 누른 「발사」 횟수) |

3개의 별은 서로 독립 조건이므로, 한 번 쏴서 tol/2 안에 들어오면 ★★, 그것이 3번 안이면 ★★★이다(1번 시도·tol/2 이내 → ★★★).

| # | 미션 | type | target | tol | 조건 |
|---|---|---|---|---|---|
| ① | 중신기전 200m | jung | 200 | 15 | 화차 100발 평균 |
| ② | 소신기전 120m | so | 120 | 10 | 화차 100발 평균 |
| ③ | 대신기전 800m | dae | 800 | 40 | 1발, **발화통 없이**(`bomb = false`) |

세부 규칙 (**v2 신규** — 위 확정 규칙을 구현 가능하게 풀어 쓴 것):

- 판정은 **화면에 보이는 정수 m**(반올림한 값)로 한다. 화면의 숫자와 성공 여부가 어긋나지 않게 하기 위함.
- 미션을 고른 상태에서 종류가 다르거나(예: 미션 ①에서 소신기전), ③에서 발화통을 단 채 쏜 발사는 판정하지 않고 「미션 조건과 달라요」 안내만 보인다. 시도 횟수에도 넣지 않는다.
- 별은 **최고 기록만 올라가고 내려가지 않는다**(`progress.missions`). 시도 횟수는 미션을 다시 고르면 0으로 되돌린다.
- 기본값으로 쏘았을 때(예: 중신기전 40°, 기본 화약량) 사거리는 약 225 m이므로 ①은 발사각이나 화약 양을 바꿔야 성공한다 — 학습 의도. (이 앱의 `sim.js`로 확인: 중 30° → 192 m, 35° → 213 m / 소 40° → 125 m / 대 화약 2.5 kg·30° → 807 m)
- 반대로 ②는 소신기전 기본값(40°)이 약 125 m라 그대로 쏘면 성공하므로, 미션을 고를 때 시작 조건을 따로 맞춘다([04 §6](04_피드백_게이미피케이션_기획서.md)).
- 화차는 최대 발사각(§4)을 넘길 수 없으므로 ①은 기본 화약량에서 대략 29~35°(100발 평균 185~215 m) 구간이 성공 범위다(위 확인값 기준, 씨앗에 따라 조금 달라짐).
- 사거리 띠·과녁은 3D 땅에 `target` 위치로 표시하고 `±tol` 범위를 띠로 보인다.

## 9. 퀴즈 채점·별 규칙

| 규칙 | 값 |
|---|---|
| 문항 수 | 8 (`Q.length`) |
| 채점 | 한 문제씩 한 번 고르면 정오 표시 + 풀이. 맞으면 `qs++` |
| 점수 | 첫 8문항 한 바퀴의 맞힌 수(0~8). 「틀린 문제 다시 풀기」는 연습이며 최고 점수를 바꾸지 않는다(**v2 신규**) |
| 별 | 4개 이상 ★ · 6개 이상 ★★ · 8개(만점) ★★★ · 3개 이하 별 없음 |
| 저장 | `progress.quiz.best` = 지금까지 최고 점수. 별은 최고 점수로 다시 계산 |

## 10. 반올림·표시 규칙

v1 `app.js`의 표시를 그대로 따른다.

| 값 | 표시 | 예 |
|---|---|---|
| 사거리(1발) | `toFixed(0)` + `m` | 957m |
| 사거리(100발) | 평균 `toFixed(0)` + `(최소~최대)` | 225m (170~270) |
| 최고 높이 | `toFixed(0)` + `m` | 44m |
| 비행 시간·레일 이탈 속도 | `toFixed(1)` + `s` / `m/s` | 6.4s |
| 추력·총추력 | 20 미만이면 `toFixed(1)`, 이상이면 `toFixed(0)` + `N` / `Ns` | 926Ns |
| 화약 양 | `prop × 1000` `toFixed(0)` + `g`, 중·소는 「(가정)」 | 3000g |
| 탄착 길이·폭 | `toFixed(1)` + `m` | 41.5m |
| 피해 면적 | `Math.round` + 천 단위 쉼표 + `m²` | 2,130m² |
| 바람 | 0이면 「없음」, 아니면 「뒷바람/맞바람 n m/s」 | 뒷바람 3m/s |
| 최대 발사각 | `Math.round` + `°` | 40° |

- 판정에 쓰는 사거리는 표시와 같은 값(반올림 후)이며, 내부 계산은 반올림하지 않는다.
- 단위는 숫자 뒤에 붙여 쓴다(공백 없음). 미션·기록 화면의 오차 표기는 `+12m` / `−7m`(부호 포함, **v2 신규**).
