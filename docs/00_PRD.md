- 문서 상태: 확정 (v2.0 구현 기준)
- 대상 저장소: `singijeon` (같은 기준을 `chukugi`, `geojunggi`에도 적용 — 「공통 키트」 절 참고)
- 관련 문서: [01 핵심 로직](01_핵심로직_계산규칙_명세서.md) · [02 화면 흐름](02_화면흐름도_와이어프레임.md) · [03 콘텐츠 스키마](03_학습콘텐츠_스키마.md) · [04 피드백·게이미피케이션](04_피드백_게이미피케이션_기획서.md) · [05 MVP·PoC](05_MVP범위_기술검증.md)

## 1. 배경과 문제

v1은 내용(치수·실험값·근거)은 충실하지만 학생이 쓰기에는 다음 문제가 있었다.

| # | v1의 문제 | 근거(v1 화면) |
|---|---|---|
| P1 | 한 화면에 조작이 너무 많다 | 발사 탭에 조절 항목 9개 + 읽을 값 10개가 한꺼번에 보임 |
| P2 | 글자가 작고 빽빽하다 | 본문 12~13px, 보조 설명 11px, 버튼 높이 26px |
| P3 | 어디서부터 해야 할지 알 수 없다 | 탭 5개가 같은 무게로 나열, 순서·진행 표시 없음 |
| P4 | 말이 어렵다 | 「관통장부」「비추력」「텀블링」이 풀이 없이 나옴 |
| P5 | 3D가 밋밋하다 | 각진 상자 조합, 단색 배경, 환경광 없음, 불꽃·연기 없음 |
| P6 | 환경에 맞출 방법이 없다 | 글자 크기·테마·그래픽 품질·소리를 바꿀 수 없음 |
| P7 | 다시 올 이유가 없다 | 진행 기록·목표·보상이 없음 |

## 2. 목표와 비목표

**목표**
1. 초등 5학년~중학 2학년 학생이 **설명 없이 3분 안에** 첫 발사까지 간다.
2. 수업 한 차시(40~45분) 안에 「만들기 → 구조 → 화약 → 발사 → 퀴즈」를 끝낼 수 있다.
3. 교실의 낮은 사양 노트북·태블릿에서도 끊기지 않는다(그래픽 품질 3단계).
4. v1의 모든 사실·수치·근거 표시(기록/추정/가정)를 **그대로 보존**한다.

**비목표(v2에서 하지 않음)**
- 회원 가입·서버 저장·학급 관리(→ 05 문서에서 근거 설명)
- 외부 3D 모델 파일(glTF) 도입 — 단일 HTML·오프라인 원칙 유지
- 새로운 역사 내용 추가 (내용 범위는 v1과 같음)

## 3. 사용자

| 사용자 | 상황 | 필요한 것 |
|---|---|---|
| 학생 (초5~중2) | 교실 태블릿·노트북, 1인 1기기 또는 모둠 | 큰 글자, 쉬운 말, 다음에 할 일이 보이는 화면 |
| 교사 | 교실 TV·빔프로젝터로 시연 | 아주 큰 글자, 고대비, 소리 끄기, 근거 자료 |
| 일반 관람자 | 휴대전화로 링크를 열어 봄 | 세로 화면에서도 3D와 설명이 함께 보임 |

## 4. 핵심 설계 원칙

1. **한 화면에 한 가지 일** — 3D 무대 + 카드 한 장. 나머지는 접어 둔다.
2. **쉬운 말 먼저, 자세한 것은 펼쳐서** — 모든 설명은 「쉬운 설명」 한두 문장이 먼저, 치수·근거·전문 용어는 「더 알아보기」.
3. **순서가 보인다** — 메뉴에 번호와 완료 표시(✓). 카드 아래에 항상 「다음」 버튼.
4. **기본값으로 바로 된다** — 발사는 아무것도 안 바꾸고 「발사」만 눌러도 된다. 고급 조건은 접혀 있다.
5. **사실과 추정을 구분한다** — 기록 / 추정 / 가정 딱지는 v1대로 유지.
6. **설정은 한곳에** — ⚙ 설정 메뉴. 바꾸면 바로 반영, 기기에 저장.

## 5. 기능 요구사항

### 5.1 화면 뼈대 (F-SHELL)
- F-SHELL-1 상단 바: 제목 · 번호 붙은 메뉴 5개(① 만들기 ② 구조 ③ 화약 ④ 발사 ⑤ 퀴즈) · 오른쪽에 [🏅 내 기록] [❔ 도움말] [⚙ 설정].
- F-SHELL-2 본문: 왼쪽 3D 무대, 오른쪽 패널(너비 380px). 폭 900px 이하에서는 위 3D(화면 높이의 52%) · 아래 패널.
- F-SHELL-3 3D 무대 위 표시: 위쪽 가운데 제목 띠, 오른쪽 위 확대·축소·처음 시점 버튼, 왼쪽 아래 조작 안내.
- F-SHELL-4 처음 방문 시 3장짜리 도움말(무대 돌리기 · 메뉴 순서 · 설정 위치). 「다시 보지 않기」 저장.
- F-SHELL-5 본문 글자 16px 이상, 보조 글자 14px 이상, 누르는 곳은 높이 44px 이상.
- F-SHELL-6 키보드: Tab으로 모든 조작 가능, Esc로 창 닫기, ←/→로 만들기 단계 이동.

### 5.2 만들기 (F-BUILD)
- 10단계 조립. 카드에 단계 제목 · 쉬운 설명 · 「이전 / 다음」 큰 버튼 · 단계 점(●○○…) 진행 표시.
- 「더 알아보기」를 펼치면: 자세한 설명, 기록/추정 딱지, 결구 확대 3D(짜임이 벌어졌다 맞춰지는 애니메이션).
- 「차례로 보기」(자동 재생), 「부재 떼어 보기」.
- 단계 목록은 「전체 단계 보기」로 접어 둔다.

### 5.3 구조 (F-ARROW)
- 「나란히 / 대 / 산화 / 중 / 소 / 약통 단면」 고르기. 쉬운 설명 먼저, 치수표는 「더 알아보기」.

### 5.4 화약 (F-POWDER)
- 3장 카드로 나눔: ① 재료 세 가지 ② 염초 만들기(10단계) ③ 약통에 채우기. 안전 안내는 항상 보임.

### 5.5 발사 (F-LAUNCH)
- 기본 조작 3개: 신기전 종류(큰 버튼 4개) · 화약 양 · 발사각. 그리고 큰 「발사」 버튼.
- 「고급 조건」 접기: 철침 길이, 발사대 레일, 발화통 달기, 바람, 피해 반경(가정).
- 결과: 큰 숫자로 사거리 하나. 최고 높이·비행 시간 등 나머지는 「자세한 결과」 접기.
- 궤적 그래프, 실험 사거리 띠는 유지.
- **과녁 맞히기 미션** 3개(04 문서). 미션을 고르면 과녁이 3D 땅에 표시된다.
- 연출: 불꽃·연기, 발사음, 탄착 먼지.

### 5.6 퀴즈 (F-QUIZ)
- 8문항, 한 문제씩. 맞히면 즉시 풀이. 끝나면 별 0~3개와 「틀린 문제 다시 풀기」.

### 5.7 설정 메뉴 (F-SET)

| 항목 | 값 | 기본 | 설명 |
|---|---|---|---|
| 글자 크기 | 보통 / 크게 / 아주 크게 | 보통 | 전체 글자 100% / 115% / 130% |
| 화면 색 | 밝게 / 어둡게 / 고대비 | 밝게 | 고대비는 교실 TV·저시력용 |
| 설명 수준 | 쉬운 설명 / 자세히 | 쉬운 설명 | 「자세히」는 「더 알아보기」를 처음부터 펼침 |
| 그래픽 품질 | 자동 / 낮음 / 보통 / 높음 | 자동 | 그림자·해상도·연기 입자 수 |
| 3D 이름표 | 켬 / 끔 | 켬 | 무대 위 치수·부재 이름표 |
| 소리 | 켬 / 끔 + 크기 | 켬, 60% | 효과음 |
| 움직임 줄이기 | 켬 / 끔 | 기기 설정 따름 | 카메라 이동·흔들림 최소화 |
| 기록 지우기 | 버튼 | — | 진행 기록·배지 초기화(확인 후) |

- 설정은 `localStorage`의 `singijeon.settings.v1`에 저장. 바꾸는 즉시 반영(새로 고침 없음).

### 5.8 내 기록 (F-PROG)
- 메뉴별 완료 표시, 배지, 퀴즈 최고 점수, 미션 별. `singijeon.progress.v1`에 저장.

## 6. 3D 모델링·렌더링 요구사항

| 항목 | v1 | v2 |
|---|---|---|
| 색·톤 | 선형 출력 | ACES 톤매핑 + sRGB |
| 하늘·환경광 | CSS 그라데이션 배경 | 대기 산란 하늘(Sky) + 그 하늘로 만든 환경맵(PMREM) |
| 그림자 | 기본 그림자 2048 | 부드러운 그림자(PCF Soft), 품질별 0 / 1024 / 2048 / 4096 |
| 땅 | 단색 점 무늬 평면 | 흙 마당 + 풀밭 질감, 먼 산 능선, 안개로 원근 |
| 나무 부재 | 각진 상자 | 모서리를 둥글린 부재, 나뭇결 + 요철(bump) 질감 |
| 바퀴 | 원환체(도넛) 조각 | 네모 단면의 굽은 테(휜 부재), 깎은 살, 통 모양 바퀴통 + 쇠테 |
| 원공목통 | 상자 + 검은 원 | 실제로 뚫린 구멍 |
| 신기전 | 원통 조합 | 대나무 마디, 종이 약통 + 묶은 끈, 화살촉, 깃 모양 |
| 발사 연출 | 주황 원뿔 | 불꽃(가산 혼합) + 연기 입자 + 탄착 먼지 |

- 성능 기준: 「보통」 품질에서 내장 그래픽 노트북 30fps 이상, 「낮음」에서 보급형 태블릿 30fps 이상.
- 모든 모형은 코드로 생성(외부 파일 없음). 치수는 `sim.js`의 기록값을 그대로 쓴다.

## 7. 공통 키트 (세 앱 공용)

`src/kit/` 아래 파일은 세 저장소에 **같은 내용으로 복사**해 화면과 설정이 같게 한다.

| 파일 | 역할 |
|---|---|
| `kit.css` | 색·글자 토큰, 화면 뼈대, 카드·버튼·접기·대화창 스타일, 테마 3종 |
| `settings.js` | 설정 저장·불러오기, 설정 창, 문서에 반영 |
| `progress.js` | 진행 기록·배지 저장, 「내 기록」 창 |
| `sfx.js` | 효과음(Web Audio 합성, 음원 파일 없음) |
| `stage.js` | 렌더러·하늘·땅·조명·품질 단계·카메라 이동·이름표 |
| `ui.js` | 도움말, 대화창, 알림(토스트), 접기 등 작은 도구 |

앱마다 다른 것: 앱 ID(저장 키 접두어), 메뉴 구성, 강조색, 콘텐츠.
